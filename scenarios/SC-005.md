# Scenario card: SC-005

- **ATT&CK technique:** T1547.001 - Boot or Logon Autostart Execution: Registry Run Keys
- **Objective:** Add a registry value to the current user's Run key, the classic persistence technique, and see if Sysmon/Wazuh catch the write itself.
- **Prerequisites:** Sysmon running with registry monitoring enabled (default in the Neo23x0 config).
- **How to run it:** Add a harmless Run key value pointing to notepad.exe, then remove it.
- **Expected telemetry:** Sysmon Event ID 13 (Registry value set) for the HKCU Run key.
- **Cleanup:** Remove the added registry value immediately after.
- **Safety notes:** Points only to notepad.exe, does nothing if left in place, but is removed anyway.
