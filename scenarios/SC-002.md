# Scenario card: SC-002

- **ATT&CK technique:** T1059.001 - Command and Scripting Interpreter: PowerShell
- **Objective:** Simulate a suspicious PowerShell command execution, the kind an attacker uses to run malicious code, and confirm Sysmon + Wazuh detect it.
- **Prerequisites:** Sysmon installed and confirmed working on win-client (see INV-002).
- **How to run it:** Run a harmless but suspicious-looking PowerShell one-liner from an elevated PowerShell window on win-client.
- **Expected telemetry:** Sysmon Event ID 1 (Process Create) showing powershell.exe launched with an encoded or unusual command line.
- **Cleanup:** None needed, no files or persistence created.
- **Safety notes:** Command only downloads nothing and makes no changes; it just demonstrates the command-line pattern.
