# Scenario card: SC-003

- **ATT&CK technique:** T1053.005 - Scheduled Task/Job: Scheduled Task
- **Objective:** Create a scheduled task the way an attacker would to gain persistence, and see whether Sysmon and Windows' own Security log both capture it.
- **Prerequisites:** Sysmon running on win-client (confirmed, INV-002/INV-003).
- **How to run it:** Use schtasks.exe to create a task, then delete it immediately after.
- **Expected telemetry:** Sysmon Event ID 1 (process create for schtasks.exe) always. Windows Security Event 4698 (scheduled task created) only if that specific audit subcategory is enabled, which it usually isn't by default, a likely gap worth testing.
- **Cleanup:** Delete the task immediately after confirming it was created.
- **Safety notes:** The task runs nothing malicious, it just calls whoami.exe once and is removed right after.
