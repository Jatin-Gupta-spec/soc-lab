# Scenario card: SC-004

- **ATT&CK technique:** T1070.001 - Indicator Removal: Clear Windows Event Logs
- **Objective:** Simulate an attacker clearing a Windows event log to cover their tracks, and see whether the act of clearing itself gets detected.
- **Prerequisites:** Wazuh agent Active on win-client, Sysmon running.
- **How to run it:** Clear the Application log using wevtutil.exe (a safe, low-stakes log to target, doesn't affect Sysmon or Security history).
- **Expected telemetry:** Sysmon Event ID 1 (process create for wevtutil.exe with "cl Application" in the command line), plus a Windows-generated Event ID 104 in the Application log itself ("The Application log file was cleared").
- **Cleanup:** None needed, no persistence created.
- **Safety notes:** Targets only the Application log, not Security or Sysmon's own log, so this scenario's own evidence trail stays intact.
